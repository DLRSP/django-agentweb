# Commerce & booking

Discovery and hooks for agentic commerce/booking (CAP / UCP for Lodging / AP2).

For an independent hotel the priority use cases are: **check availability**,
**simulate a booking price**, and **start a direct reservation** — to grow
direct bookings and reduce OTA dependence. Full transactional flows are
delegated to the booking-engine vendor; this module provides the `/.well-known`
discovery surface and integration hooks.
